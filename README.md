# ZtxYuchenLabs Portfolio

Responsive single-page portfolio built with HTML, locally compiled Tailwind CSS, and vanilla JavaScript. No Tailwind CDN is used.

## Development
`npm install` then `npm run build`.

GitHub Actions builds Tailwind CSS and deploys to GitHub Pages on pushes to `main`. Edit project content in `index.html`, interactions in `script.js`, and design tokens in `src/input.css`. Primary color: `#011C6B`.
